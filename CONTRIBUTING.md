# Contributing

## Pull request guidelines

- Submit one app per pull request. Check the catalog and open pull requests for duplicates.
- The app must be publicly available and built with AI assistance. AI features are optional.
- Use the app’s official name and link. Describe what it does in one sentence and list its supported platforms. Add official store links where applicable.
- Place the entry in the most relevant category, in alphabetical order. If no category fits, propose one in the pull request.

Example README entry:

```markdown
- [Example App](https://example.com/) — A simple task planner. · **macOS, Windows**
```

## How to add an app

1. Fork this repository. If you edit the README directly on GitHub without write access, GitHub will prompt you to create a fork.
2. Add your entry to `README.md` in your fork and commit the change.
3. Open a pull request from your fork to this repository. Give it a title like `Add Example App`, fill in the [pull request template](.github/PULL_REQUEST_TEMPLATE.md), and check all supported platforms.
